Made to dogfood [league-toolkit](/projects/league-toolkit) in a WASM environment, hexbelt provides a set of basic tools to inspect various file formats found in *League of Legends*.

![Home page](/static/img/hexbelt/home.png)

Supports the browsing of `.wad` files, with texture previews & file downloads:

![Wad walker page](/static/img/hexbelt/wad.png)

Also supports the viewing of `.bin` files:

![Bin viewer page](/static/img/hexbelt/bin.png)
