Provides language support for [ritobin](https://github.com/moonshadow565/ritobin), a custom DSL to represent *League of Legends* `.bin` files in a human readable format.

Uses the `ltk_ritobin` crate, the parser I wrote for [league-toolkit](/projects/league-toolkit). Also ships as a VS Code extension, heavily based on (see: "stolen from" :3) [rust-analyzer](https://github.com/rust-lang/rust-analyzer/tree/master/editors/code)'s extension.
